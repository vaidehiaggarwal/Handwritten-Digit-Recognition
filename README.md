# Handwritten Digit Recognition using Neural Networks

## Overview
This project implements a Handwritten Digit Recognition System using Artificial Neural Networks (ANN) and the MNIST dataset. The model is trained using TensorFlow/Keras and can accurately classify handwritten digits from 0–9.

## Features
- Uses the MNIST handwritten digit dataset
- Data preprocessing and normalization
- Neural Network built using TensorFlow/Keras
- Model training and evaluation
- Predicts handwritten digits
- Achieved approximately 97% test accuracy

## Technologies Used
- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib
- OpenCV

## Dataset
MNIST Dataset
- 60,000 training images
- 10,000 testing images
- Image size: 28 × 28 pixels
